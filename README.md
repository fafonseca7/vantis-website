# Vantis Website

Single-page marketing site for Vantis (fractional consulting). Bilingual EN/PT, self-contained in `index.html`.

## Run locally

Open `index.html` in a browser, or serve it:

```bash
python3 -m http.server 8000
```

## Deploy (GitHub Pages)

Settings → Pages → Source: `main` branch, `/ (root)`. The site is served from `index.html`.
